# Decisions

- **Heuristic-first extraction, LLM fallback.** Brief names LLM extraction; a deterministic tabular parser covers standard layouts so the golden PDF suite runs without network/key, and the LLM path (same zod schema, retry once, needs-review) handles layouts the parser can't. Keeps DoD testable and the product usable key-less.
- **Fixture PDFs generated by committed script (pdf-lib)** rather than checked-in binaries authored by hand — layouts stay editable, expected-value JSON lives beside each PDF.
- **`idb` wrapper over raw IndexedDB** — small, typed, no framework lock-in.
