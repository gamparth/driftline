# Driftline

Driftline is a local-first health records timeline for lab-report PDFs. It reads reports in the browser, normalizes markers across labs and units, shows longitudinal trends, and prepares a visit summary without requiring an account or backend.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npm test
npm run build
```
